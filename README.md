# 🌱 Spring Boot Learning Journey

Welcome to my **Spring Boot Learning Journey** repository!

This repository documents my progress as I learn **Spring Boot** from the ground up. My goal is not only to understand the framework but also to apply what I learn by building a complete, production-style web application by the end of this journey.

Rather than uploading only finished projects, this repository serves as a chronological record of my learning process, experiments, practice code, and mini-projects.

---

## 🎯 Goal

The primary objective of this repository is to:

* Learn the fundamentals of Spring Boot
* Understand how modern Java backend applications are built
* Gain hands-on experience with industry-standard development practices
* Build a fully functional web application from scratch by the end of the learning journey
